# Sprint 3 Differentiation Audit - Channel Comparison

## Why Reset Was Required
All five initial implementations were derived from one shared structural component (`AgentShellChannelComparison`) with only local style branching.  
Result: same panel architecture, same delta placement, same winner hierarchy, same chart grammar.

## Extracted Similarities From Prior Pass
1. Channel panel structure: identical card shell and metric order.
2. Delta system: same per-row placement and same sentence syntax.
3. Winner treatment: same banner layout with minor visual tweaks.
4. Chart strategy: same line chart with lightly varied stroke/band settings.

## Structural Rebuild Requirements (Locked)
Each territory now diverges structurally on the four convergence-prone surfaces.

### Agent 1 - Minimal Geometric
1. Panel layout: borderless typographic columns with vertical dividers.
2. Delta treatment: monochrome inline directional notation in metric lines.
3. Winner banner: compact rail with no hero composition.
4. Chart strategy: single-layer line graph, no confidence area fill.

### Agent 2 - Data-Forward Density
1. Panel layout: dense matrix table (metrics as rows, channels as columns).
2. Delta treatment: inline differential bar + numeric text in each matrix cell.
3. Winner banner: dark analytical strip with histogram-like distribution row.
4. Chart strategy: composed chart with confidence fills and high data density.

### Agent 3 - Editorial Luxury
1. Panel layout: editorial cards with ROAS as typographic hero.
2. Delta treatment: oversized callout line anchored beneath hero value.
3. Winner banner: verdict stage with dominant typography.
4. Chart strategy: winner-emphasis chart (thick winner line, muted peers).

### Agent 4 - Systematic Modularity
1. Panel layout: modular cards with formalized section rows.
2. Delta treatment: separate inter-panel ribbon module (adjacent panel comparisons).
3. Winner banner: explanatory system-status block.
4. Chart strategy: tabbed chart metric switcher (Revenue/ROAS/Spend).

### Agent 5 - Atmospheric Technical
1. Panel layout: confidence-reactive ambient cards.
2. Delta treatment: atmospheric metric lines with motion-signaled polarity.
3. Winner banner: animated non-overlap confidence glyph.
4. Chart strategy: animated sequential trend lines with reactive atmosphere.

## Acceptance Criterion For Reconvening Compare All
Storybook `Compare/Channel Comparison/Compare All` is considered acceptable only when a reviewer can identify each territory by structure (not color/spacing) within 5-10 seconds.
