## 0. Pre-flight discipline (skeldir-engineering-preflight-skill)

The five pre-implementation questions were answered in writing before code changed:

- **Q1 — Defect class (effects, not symbols).** The system can believe `CANONICAL_SEMANTICS(C, t) == CANONICAL_SEMANTICS(C, t0)`

  canonical authoritative meaning (post-issuance authoritative state mutation). `list.append("shopify")` instantiates

  contract YAML + AST pin, `tenant_hash`, and the existing `freeze_platform_scope` snapshot boundary. Composed with

- **Q4 — Sibling surfaces.** Same capability: `__getitem__`, `dict()`, `items()`/`values()`/iteration, the `_fields`
  storage slot (item-write AND slot-rebind), issuance-input aliasing, wire/serialization copies, future fields under
  new type labels, tuple-with-mutable-child, the live `EXTERNAL_SEMANTICS` registry and its spec objects, and the
  future B2.5 handoff payload. Each received its own sensor and negative control.
- **Q5 — Adversarial candidate.** Mutations that avoid every previously scanned symbol: `clear()` to an empty scope
  (maximal semantic change), `dict(capability)` write-back, plain-attribute slot rebind (`cap._fields = …`, no
  dunders), issuance-input aliasing across two issuances, module-attribute rebinding of the live registry, and

## 4. Remediation design (deep authority immutability by construction)

Selected from the measured object graph (not prescribed): the capability's only nested value is an ordered string
scope, so canonical storage is a **fresh immutable tuple**; the general law is **recursive freeze + verify**:

- `freeze_canonical_value`: sequences (tuple/list) → fresh tuples with frozen members; mappings (dict/proxy) →
  fresh read-only mappings with `str` keys and frozen values; exact `str`/`int`/`bool` pass; sets, bytearrays,
  datetimes, Decimals, `None`, custom containers → refuse closed.
- `assert_canonical_value_frozen`: tuples/proxies recurse; raw `list`/`dict` refuse even with frozen contents.
- Constructor: live-identity re-verify → key census → freeze → assert → semantic law → seal in `MappingProxyType`.
- `__setattr__`/`__delattr__` always refuse (closes the demonstrated plain-assignment slot rebind; construction
  uses `object.__setattr__` directly; `object.__setattr__`/closure introspection remain declared-TCB as since VII).
- Reads return stored immutable references (provably alias-safe); `dict()`/`items()` outer copies hold immutable
  values; `to_wire_dict` projects fresh JSON-ready copies (tuples→lists) that are never admitted.
- `check_external_semantics`: `tuple[str]` branch (exact tuple, non-empty `str` members), `mapping` branch
  (read-only + recursively frozen), `else` → refuse unknown families closed.
- `GOVERNED_CANONICAL_EXTERNAL_TYPES = {str, int, bool, tuple[str], mapping}` — the closed universe, pinned
  independently by the validator.
- Live registry: `MappingProxyType` over `_EXTERNAL_SEMANTICS_STORE`; `_PINNED_EXTERNAL_SPECS` captured at import;
  `_verify_live_semantics_identity()` at issuance and admission (sensor only — confers no authority).
- Contract: same version (representation hardening; meaning/keys/transform_ids/wire unchanged — see §9), AST pin
  advanced to the reviewed XII bytes.
