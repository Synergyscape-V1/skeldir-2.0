`backend/app/finance_reconciliation/external_semantics.py`: one governed

executes hard-coded value vectors and refusal vectors against every
transform and pins key→source lineage as value-blind data. The renderer
contains **no per-field transform expressions at all** — transform drift at
the renderer layer is unrepresentable.

now returns `CanonicalExternalTruth`: an exact-type sealed `Mapping` born in
a closure with a per-process issuance secret, whose constructor
validates-then-freezes exactly the contract-projected fields into a
`MappingProxy`. Admission (`admit_canonical_external`) accepts only that
exact type and re-verifies the semantic law live. Reproducing the lawful
bytes — by any construction primitive — is ordinary data and refuses at
admission. The egress surfaces form the registered closed set
`GOVERNED_EGRESS_SURFACES` (census-pinned in validator + consequence tests);
a second surface is a three-file machine-visible registration event.
Class XI-C (validate-A/return-B) is closed by construction: no intermediate
mapping exists; the issuer freezes what it validates.

**Static plane (validator `_validate_corrective_xi_authority`).** 17 sensor
families: contract pin (AST), census, value-blind lineage pins, transform-id
pins, execution/refusal vectors, projection equivalence, renderer/issuer
structure laws (no Dict/dict()/DictComp in either; return must be the sealed
issuance), repo-wide capability census (construction, subclassing, aliasing,
**and aliased ImportFrom bindings** of the capability/issuance names outside
the governed module), egress-registry census + binding law, admission
