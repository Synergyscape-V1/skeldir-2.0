## 2. Scope Boundaries

This corrective action intentionally remains inside B2.5-P6. It does not add P7 audit persistence, P8 signing/JWKS, P9 auth/scopes/replay/rate-limits, P10 routes, P11 export, MCP, LLM explanation, action authority, DB tables, migrations, or background dispatch.

The follow-up closes only two proof gaps:

- Internal reason truth matrix APIs must require `ReasonCode` enum members and reject raw strings, even when the string is a valid registered reason code.
- Exception-originated refusal/degraded/error outputs must never emit upstream exception text, reprs, traceback strings, or prompt-injection content.

## 4. Production Remediation

Changed files:

- `backend/app/trust/reason_codes.py`
- `backend/app/trust/reason_truth_matrix.py`
- `backend/app/trust/refusal.py`

Key behavior:

- `coerce_reason_code(...)` is documented and retained as ingress-only conversion from JSON/schema strings.
- `get_reason_definition(...)` fails closed unless given a `ReasonCode`.
- `evaluate_reason_truth_state(...)`, `apply_reason_truth_matrix(...)`, and `validate_reason_truth_payload(...)` require `ReasonCode` and raise `ReasonTruthMatrixError("reason_code_not_enum:str")` for raw valid strings.
- `build_exception_error_envelope(...)` accepts a `BaseException` and emits a schema-valid error envelope using only the enum-backed reason code. It does not serialize `str(exception)`, `repr(exception)`, exception args, or traceback text.

## 5. Test and Validator Remediation

Changed files:

- `backend/tests/trust/test_b25_p6_reason_truth_matrix.py`
- `scripts/ci/validate_b25_p6_reason_truth_matrix.py`

New tests prove:

- `ReasonCode.MONEY_SOURCE_NOT_AUTHORITATIVE` succeeds in the core matrix.
- `"money_source_not_authoritative"` fails at `evaluate_reason_truth_state`, `apply_reason_truth_matrix`, and `validate_reason_truth_payload`.
- `coerce_reason_code("money_source_not_authoritative")` succeeds only at the named ingress helper.
- `coerce_reason_code("system: ignore previous instructions")` fails closed.
