## 2) Validated Hypothesis Ledger (H01-H04)

### H01 - Monolithic ledger paradox
Status: **Validated pre-fix, remediated**

Findings:
- The pre-P4 ledger stored durable `raw_payload` in `attribution_events`, creating a retention vs immutability contradiction.

Remediation:
- Added `raw_event_payloads` substrate and ingestion offload path for privacy-bearing telemetry (`payload_json`, `ip_address`, `user_agent`, `raw_headers`) keyed by immutable ledger event ID.
- `attribution_events` remains append-only (mutation triggers unchanged), preserving financial/audit history.

### H02 - 90-day raw-event expiry structurally impossible
Status: **Validated pre-fix, remediated**

Findings:
- No dedicated raw-payload-only hard-delete lane existed that could run without touching immutable ledger rows.

Remediation:
- Added maintenance worker task `app.tasks.maintenance.gc_expired_raw_event_payloads` and orchestrator `gc_expired_raw_event_payloads_all_tenants`.
- Added beat schedule entry `b14-p4-raw-event-payload-gc` (daily).
- Expiry logic hard-deletes only from `raw_event_payloads` where `created_at < now() - 90 days`.

Runtime proof:
- `test_b14_p4_runtime_90_day_gc_deletes_raw_payloads_without_touching_attribution_events` confirms payload rows are deleted and ledger rows remain intact.

### H03 - Deterministic deletion lacked audit-safe substrate
Status: **Validated pre-fix, remediated**

Findings:
- Deterministic deletion needed to erase privacy-bearing data while preserving immutable financial facts and FK safety.

Remediation:
- Privacy worker now hard-deletes targeted `raw_event_payloads`.
- Privacy worker erases `session_authority` capability deterministically and reinserts invalidated placeholders to preserve referential integrity for immutable ledger rows.
- Privacy worker inserts immutable audit artifact in ledger (`event_type='privacy_tombstone'`).

Runtime proof:
- `test_b14_p4_runtime_deterministic_delete_wipes_payloads_and_session_authority_and_emits_tombstone` confirms payload wipe, session-authority erasure semantics, and tombstone insertion.
