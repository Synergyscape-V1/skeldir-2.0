## 0) Follow-Up Corrective Addendum (2026-03-21)

This addendum addresses the corrective-action directive focused on reporting-surface truth, conversion-path truth, webhook recompute coverage, and telemetry sufficiency without reopening durable cross-session identity reconstruction.

Validated findings from this corrective pass:
- Export/read path was over-constrained: `/api/export/revenue`, `/api/export/csv`, `/api/export/json` previously returned no attribution rows when `X-Attribution-Session-ID` was omitted.
- Stripe v2 webhook runtime gap was real: `/api/webhooks/stripe/payment_intent/succeeded` success path did not schedule downstream attribution recompute/matview refresh.
- Conversion continuity remained weak for async Stripe conversions unless session continuity could be explicitly hinted.
- Existing P3 runtime proofs emphasized privacy-negative controls, but did not explicitly prove aggregate-reporting viability under session-authority constraints.

Corrective remediations implemented in this pass:
- Export partition corrected in `backend/app/api/export.py`:
  - Maintains session-scoped output when `X-Attribution-Session-ID` is provided.
  - Restores privacy-safe aggregate reporting across active session-authority scopes when header is omitted.
  - Keeps authority guard (`JOIN session_authority`, `invalidated_at IS NULL`, `expires_at > now`) on all export reads.
- Stripe v2 operational gap closed in `backend/app/api/webhooks.py`:
  - Added downstream scheduling parity (`_schedule_downstream_tasks`) on success path.
  - Added bounded continuity hook: accepts `metadata.session_id` / `metadata.skeldir_session_id` only if UUID-shaped, then relies on `resolve_session_authority` for active-scope reuse/fail-closed behavior.
- Proof-plane expansion:
  - Extended runtime suite (`backend/tests/integration/test_b14_p3_attribution_locality_runtime.py`) with:
    - aggregate + session-scoped export partition proof,
    - bounded telemetry positive sufficiency proof,
    - forbidden proxy telemetry fail-closed proof,
    - Stripe v2 recompute coverage + session-hint continuity proof.
  - Extended structural enforcer (`scripts/ci/enforce_b14_p3_attribution_locality.py`) to prevent:
    - regression back to single-session-only export empties,
    - Stripe v2 recompute scheduling omission,
    - Stripe v2 session-hint continuity removal,
    - omission of new runtime proofs.
