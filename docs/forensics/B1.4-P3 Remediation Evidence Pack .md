## 2) Corrective Hypothesis Ledger

### H01 - Aggregate export destroyed historical ROAS via authority TTL gate
Status: **Validated pre-fix, remediated**

Findings:
- `backend/app/api/export.py` previously enforced `sa.expires_at > :authority_now` in the export query path even when no session header was provided.

Remediation:
- Export query is now explicitly partitioned:
  - Aggregate mode (`session_scope is None`): no `session_authority` TTL predicate.
  - Session-scoped raw mode (`X-Attribution-Session-ID` provided): still enforces active `session_authority`.

Proof:
- Runtime test `test_b14_p3_runtime_export_partition_preserves_aggregate_and_session_scoped_reporting` now expires session authority rows and still validates non-zero aggregate reporting.

### H02 - Webhook continuity was Stripe metadata-bound and structurally incomplete
Status: **Validated pre-fix, remediated**

Findings:
- Non-Stripe webhook paths generated fresh session IDs and had no shared stateful continuity layer.

Remediation:
- Introduced ephemeral order-resolution substrate (`order_id -> session_id`, 24h TTL) and wired it into ingress resolution before durable persistence.
- Added `order_id` continuity key propagation in webhook event payload assembly for Shopify, Stripe, PayPal, WooCommerce.

Proof:
- Runtime test `test_b14_p3_runtime_universal_webhook_order_resolution_adopts_active_browser_session` proves cookieless PayPal webhook adopts the browser session through the ephemeral cache.

### H03 - Deterministic click telemetry degraded due no transient click substrate
Status: **Validated pre-fix, remediated**

Findings:
- No transient store existed for `click_id` continuity after durable minimization.

Remediation:
- Introduced ephemeral click-resolution substrate (`click_id -> session_id`, 24h TTL).
- Ingress now resolves candidate session via active authority, then ephemeral order/click continuity, then authority issuance.
- Ingress upserts ephemeral click continuity at write-time without persisting click identifiers in durable payload.

Proof:
- Runtime test `test_b14_p3_runtime_ephemeral_click_resolution_routes_and_expires_after_25h` proves:
  - click continuity routes conversion to the original browser session, and
  - expired click rows are physically hard-deleted by GC.

## 5) Export SQL (Authoritative)

### Aggregate reporting branch (`session_scope is None`)

```sql
SELECT
    date_trunc('day', e.occurred_at)::date AS export_date,
    aa.channel_code AS channel_code,
    COALESCE(SUM(aa.allocated_revenue_cents), 0)::bigint AS revenue_cents,
    COUNT(DISTINCT aa.event_id)::bigint AS conversion_count,
    COALESCE(AVG(aa.confidence_score), 0)::numeric AS confidence_score
FROM attribution_allocations aa
JOIN attribution_events e
  ON e.id = aa.event_id
 AND e.tenant_id = aa.tenant_id
WHERE aa.tenant_id = :tenant_id
  AND e.occurred_at >= :start_ts
  AND e.occurred_at < :end_ts
  AND (
        :channels_is_empty
        OR lower(aa.channel_code) = ANY(CAST(:channels AS text[]))
  )
GROUP BY export_date, aa.channel_code
ORDER BY export_date ASC, aa.channel_code ASC
```

### Session-scoped raw branch (`X-Attribution-Session-ID` provided)

```sql
SELECT
    date_trunc('day', e.occurred_at)::date AS export_date,
    aa.channel_code AS channel_code,
    COALESCE(SUM(aa.allocated_revenue_cents), 0)::bigint AS revenue_cents,
    COUNT(DISTINCT aa.event_id)::bigint AS conversion_count,
    COALESCE(AVG(aa.confidence_score), 0)::numeric AS confidence_score
FROM attribution_allocations aa
JOIN attribution_events e
  ON e.id = aa.event_id
 AND e.tenant_id = aa.tenant_id
JOIN session_authority sa
  ON sa.tenant_id = e.tenant_id
 AND sa.session_id = e.session_id
WHERE aa.tenant_id = :tenant_id
  AND e.session_id = :session_id
  AND e.occurred_at >= :start_ts
  AND e.occurred_at < :end_ts
  AND sa.invalidated_at IS NULL
  AND sa.expires_at > :authority_now
  AND (
        :channels_is_empty
        OR lower(aa.channel_code) = ANY(CAST(:channels AS text[]))
  )
GROUP BY export_date, aa.channel_code
ORDER BY export_date ASC, aa.channel_code ASC
```
