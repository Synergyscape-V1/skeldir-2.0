## 9-10. Physical Streaming Proof

`stream_source_chunks()` now uses:

- `session.stream(query.execution_options(...), params)`
- `stream_results=True`
- `yield_per=SOURCE_STREAM_PARTITION_SIZE`
- `max_row_buffer=SOURCE_STREAM_MAX_ROW_BUFFER`
- `stream.mappings().partitions(SOURCE_STREAM_PARTITION_SIZE)`

The large-source unit proof exercises partitioned streaming and verifies bounded execution options are attached to each source query. Validator negative controls reject `fetchall`, `.all()`, `list(rows)`, full-manifest `json.dumps`, and missing `partitions()`.

## 11-13. Schema Drift, Serialization, OFFSET

Source rows now pass through `_contract_row_payload(source_name, dict(row))`, which rejects non-contract fields before canonical encoding. Validator negative controls reject:

- `SELECT *`
- `row.__dict__`
- `vars(row)`
- reflected column enumeration such as `__table__.columns`
- source-row encoding without the contract allowlist
- SQL `OFFSET`
- SQLAlchemy `.offset(...)`
