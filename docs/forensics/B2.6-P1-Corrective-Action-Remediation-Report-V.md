## 7. Defect-class register

Format: observed instance → failure class → consequence boundary →
equivalence set (≥5 mechanisms) → class-closure theorem. Each theorem
was tested against multiple distinct primitives on host and container.

A. Tenant/truth authority split. Observed: Tenant-A session +
   Tenant-B parameter → canonical-looking `0/0`. Class: database
   visibility authority can differ from financial scope authority.
   Boundary: the point where an aggregate becomes canonical B2.6 truth.
   Equivalence: (1) mismatched `tenant_id` parameter; (2) missing GUC;
   (3) mid-transaction `set_config` switch; (4) stale pooled GUC;
   (5) scope-tenant mutation after authentication;
   (6) alternate-DB same-schema session. Closure theorem: canonical
   financial scope and transaction-bound database tenant authority are
   one machine-enforced identity before any aggregate is accepted
   (`assert_tenant_authority` pre + post aggregation; mismatch/missing
   refuses, never zero).

B. Caller-controlled session capability. Observed: resolver accepts an
   externally supplied `AsyncSession`. Class: the caller chooses the
   database capability with which sovereign truth is derived.
   Boundary: sovereign read. Equivalence: (1) raw caller session;
   (2) alternate session factory; (3) test-double session;
   (4) alternate principal session; (5) alt-database session;
   (6) mid-transaction GUC-switched session. Closure theorem: the
   canonical authority boundary obtains its own governed capability
   through the approved production session factory; the canonical
   executor takes no session/engine/factory parameter
   (structurally impossible — verified by signature introspection in
   CI on every run).

C. Symbolic sink governance. Observed: sink identity is string
   membership. Class: semantic authority name separable from executable
   consequence. Boundary: canonical emission. Equivalence:
   (1) wrong-module same-name claim; (2) neutral-module emitter;
   (3) alias import; (4) dynamic import; (5) network-fetched name;
   (6) future successor self-naming. Closure theorem: canonical status
   is available only to executable consumers registered through the
   machine-governed contract (`SINK_REGISTRY` + decorator binding
   id → implementation → contract → source → modes → proofs); CI loads
   the registry and executes each registered implementation.

D. Resolver-decoy consumer. Observed: future sink may call resolver
   correctly then emit another value. Class: proof of source contact
   mistaken for proof of final-output dependency. Boundary: final
   authoritative field. Equivalence: (1) constant substitute;
   (2) legacy substitute; (3) caller-value substitute;
   (4) LLM/B2.4/B2.13 substitute; (5) coherent post-resolution
   replacement (even numerically equal); (6) omitted-then-defaulted
   field. Closure theorem: canonical financial fields are materialized
   by the trusted sink framework from the resolver result after the
   projection callback returns; projection code supplies adjuncts only
   and any authoritative/tenant-bearing adjunct key is refused.

E. Coherence-as-provenance. Observed: synthetic/copied/reconstructed/
   adjacent-domain objects pass scope/math coherence. Class: internal
   consistency separable from physical source correspondence.
   Boundary: canonical read. Equivalence: (1) coherent synthetic
   `50K/100K/50%`; (2) `deepcopy`/`replace` rebuild; (3) `asdict`
   round-trip; (4) shifted-window coherent forgery;
   (5) cross-tenant coherent copy; (6) serialized caller JSON.
