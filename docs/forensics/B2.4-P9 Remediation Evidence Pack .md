   - Sync artifact persist, verify, and prune paths now require an already-bound transaction-local tenant GUC.

   - Added sentinel-based failure-payload proof that retained child stream bytes are not serialized into parent payloads.
   - Added child-per-fit/native lifecycle proof showing the parent does not import `pymc`, `pytensor`, or `arviz`, launches a distinct child PID, kills/reaps it under supervision, and removes the compiledir.

6. `backend/tests/test_b24_p9_postgres_runtime.py`

   - Added session-level GUC poisoning proof showing rollback-on-return is not treated as sufficient cleanup.
   - Added multi-transaction task-flow proof with a negative omitted-bind artifact transaction.
   - Added barrier-synchronized concurrent Tenant A/B proof using independent DB connections, distinct runtime paths, distinct artifact refs, no cross-tenant row visibility, and clean GUC checkout after commit.

6. There was no P9-specific static negative-control validator or Postgres runtime proof gate.
