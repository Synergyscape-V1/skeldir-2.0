## Initial Findings

1. Worker tenant binding existed in the runtime path, but there was no reusable `SET LOCAL` tenant-context helper with a checkout-clean proof.
2. The PyTensor compiledir lease was attempt-scoped, but not explicitly tenant-, fit-, and source-snapshot-hash scoped.
3. Child IPC files lived beneath the compiledir lease, conflating compiled artifacts with transient execution workspace state.
4. Artifact references were fit-scoped (`b24://artifact/{fit_id}/...`) and omitted tenant authority from the durable URI.
5. Child failure payloads exposed retained stderr text to the parent result payload.
6. There was no P9-specific static negative-control validator or Postgres runtime proof gate.
7. Governance files did not list an independent `B2.4-P9 Worker Tenant Hygiene Proof` required context.
