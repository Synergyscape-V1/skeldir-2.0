## 6. Self-caught near-miss (hostile-reader lesson)

My first-draft VI-2 check and validator sensor used
`import app.finance_reconciliation.canonical_sink as X`. The package
`__init__` re-exports the `canonical_sink` decorator, which **shadows the
submodule attribute**, so that binding is the *function* — and
`hasattr(function, '_ISSUED…')` is vacuously False. Both checks passed
without testing anything (Discipline 3 violation caught before submission).
Fixed with `importlib.import_module` (real module), verified the shadow
still exists (`type == function`), and re-proved all RED directions. This
shadowing is recorded as a standing hazard for future auditors.
