## 5) Session Authority Substrate Introduced

### Durable substrate

`public.session_authority`:
- `tenant_id` scoped
- `session_id` authority value
- `issued_at`, `expires_at`, `last_seen_at`
- `invalidated_at`, `invalidation_reason`
- bounded by `ck_session_authority_max_24h`
- RLS enabled with tenant isolation policy

### Event binding

- `attribution_events(tenant_id, session_id)` now FK-references `session_authority(tenant_id, session_id)`.
- Trigger `trg_bind_session_authority_from_event` guarantees authority registration on inserts and rejects stale/invalidated session references.

### Runtime authority path

- `resolve_session_authority` (ingestion runtime):
  - reuses active authority rows,
  - invalidates stale rows,
  - rotates to new UUID4 session for stale/unknown candidates.

## 6) Durable Fields Removed/Transformed/Bounded

- Deterministic session derivation removed from canonical durable ingress path.
- Session candidates are transformed into authority-issued session IDs when unknown/stale.
- Session persistence in immutable events is now bounded by explicit authority substrate + expiry state.
- No `click_id` durable event column exists in canonical schema; proxy bridge focus in P2 centered on session binding semantics.
