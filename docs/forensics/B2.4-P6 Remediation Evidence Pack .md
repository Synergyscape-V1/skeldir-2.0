# B2.4-P6 Remediation Evidence Pack

## Scope

B2.4-P6 is the real Bayesian fit worker physics bridge. It validates fit-id-only dispatch into a DB-authoritative parent worker, frozen P2/P4 source authority replay, bounded IPC into the isolated P5 child runtime, deterministic RNG seed derivation, PyMC/PyTensor compilation, byte-capped stream draining, fsynced child stage markers, and bounded summary return as `sampled_unvalidated`.

This phase is mechanical, not statistical. It does not claim convergence diagnostics, production Bayesian attribution semantics, posterior artifact lifecycle, P7/P8/P9/P10 confidence governance, frontend exposure, or LLM authority expansion.
