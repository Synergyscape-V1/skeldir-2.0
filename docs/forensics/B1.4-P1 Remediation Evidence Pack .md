### H01 - Current typed proof is vacuous/toy-scoped
Status: **Validated (pre-fix)**.

Evidence:
- Prior runtime test used a synthetic strict model engineered around primitive masks.
- It did not exercise the real operational consumer path.

Remediation:
- Introduced production-owned typed replay contract (`DLQReplayPayload`) in runtime code.
- Replaced toy proof with DB-backed real path proof:
  - persisted redacted dead-event payload,
  - validated through `DLQReplayPayload.model_validate(...)`,
  - replayed through `DLQHandler.retry_dead_event()` into canonical ingest.

### H02 - Current masking may violate downstream constrained contracts
Status: **Partially validated; bounded closure implemented**.

Evidence:
- Primitive-only proof did not cover production-constrained fields.

Remediation and adjudication:
- Relevant present-tense typed consumer is now explicit and constrained in production code:
  - `event_timestamp: datetime`,
  - `session_id: UUID`,
  - `revenue_amount: Decimal`,
  - constrained currency and conversion fields.
- Redacted payloads are validated against this contract before replay.
- Non-present consumer classes (e.g., `EmailStr` over full redacted DLQ blobs) are now prevented by CI enforcer rule against direct `model_validate(dead_event.raw_payload)` in app code.
