# B2.4-P1 Remediation Evidence Pack

## Partitioned Authority Corrective Update

The follow-up partition audit found one remaining P1 blocker: the schema had `fillfactor=90` and partition-readiness notes, but no final physical table-family decision. That state is now closed.

Remediation:

- Added migration `202605211200_b24_p1_partitioned_authority_schema.py`.
- Converted `bayesian_model_fits` to `PARTITION BY HASH (tenant_id)` with 16 initial partitions.
- Converted `bayesian_artifacts` to `PARTITION BY HASH (tenant_id)` with 16 initial partitions.
- Replaced id-only physical primary keys with `PRIMARY KEY (tenant_id, id)` on both partitioned parents.
- Preserved fit identity uniqueness over `tenant_id, model_type, model_version, source_window_start, source_window_end, source_snapshot_hash`.
- Preserved tenant-bound artifact FK `(tenant_id, fit_id) -> bayesian_model_fits(tenant_id, id) ON DELETE RESTRICT`.
- Preserved null-safe fit identity by keeping all identity columns `NOT NULL`.
- Applied `fillfactor=90` to fit child partitions.
- Updated ORM metadata, canonical SQL/YAML, runtime DB proof, and static validator negative controls.

## Corrective Finding

B2.4-P1 was implemented but not complete. Two database-authority blockers remained:

- `bayesian_artifacts.fit_id` referenced `bayesian_model_fits(id)` without tenant-bound relational integrity.
- `bayesian_model_fits` uniqueness omitted `source_window_start` and `source_window_end`.

Two guardrails were also missing: machine-enforced Bayesian zero-PII/identity-linkage protection and explicit storage-physics readiness for lifecycle updates.

## Remediation Summary

- Added `uq_bayesian_model_fits_tenant_id_id` to support composite artifact FK authority.
- Replaced artifact fit relationship with `fk_bayesian_artifacts_tenant_fit` on `(tenant_id, fit_id) -> bayesian_model_fits(tenant_id, id)`.
- Replaced hash-only fit identity uniqueness with `uq_bayesian_model_fits_tenant_model_window_snapshot`.
- Set `bayesian_model_fits` storage parameter `fillfactor=90`.
- Superseded the earlier pre-P3/P5 partition-decision deferral by physically partitioning both Bayesian authority table families.
- Hardened `validate_b24_p1_authority_schema.py` with non-vacuous negative controls for FK, uniqueness, privacy, identity linkage, and fillfactor.
- Extended runtime DB proof to include cross-tenant artifact insertion failure and physical fit identity behavior.
