### 1(a) The property this phase must guarantee

**P-XXIII — Sovereign Compositional Financial Conservation** (directive §3, lines 228–252).

For every supported production execution and committed financial state, a current
authoritative P2 financial fact must be derivable only from:

1. legitimately authenticated provider evidence;
2. correctly established provider event meaning;
3. tenant- and version-compatible persistence;
4. B2.3-authorized consequences;
5. legitimate, historically preserved corrections;
6. the canonical P2 scope and normalization law;
7. independently defensible current historical authority.

No other reachable operation may create an equivalent authoritative result without
satisfying those requirements.

The property contains two inseparable obligations:

- **Boundary integrity:** a false financial fact cannot become authoritative merely
  because several mutable representations agree (reports 69/70: the coherent 99,999
  world, portable journal, config downgrade, runtime verdict UPDATE, validator PASS).
- **Functional breadth:** a legitimate financial fact can conduct to the correct
  supported consumer result, including after new corrections and through supported
  historical states (reports 69/70: witness growth refusal, PayPal no-consequence,
  refused-lifecycle 500/pending row, missing four-disposition and signed-consumer
  journeys).

A system that refuses all corrections fails. A system that accepts all internally
consistent corrections fails. Both behaviors must be falsified. The property is
established only when the legitimate world and the reconstructed world produce
opposite, independently verified outcomes through the real consumer surface.
