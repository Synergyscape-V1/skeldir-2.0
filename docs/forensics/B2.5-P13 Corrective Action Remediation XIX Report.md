## C. Exact-main first-red, root cause, and remediation (Directive-V core finding)

### Observed physics (hosted)

On the exact `82f528c` push, `R2: Data-Truth Hardening` scenario S3 sent a missing-`event_timestamp` event through the real ingestion service. The service correctly returned `validation_error`, but the R2 ORM innocence instrument (EG-R2-FIX-5, mandatory) observed **zero non-marker ORM statements in the failure window** (`S3_NON_MARKER_ORM_STATEMENTS_COUNT=0`, instrument-consistency check EG-R2-FIX-6 also failed): the failure escaped without any durable write. `R7: Final Winning State` failed transitively through its "R7 Phase R2: Data-Truth hardening" step plus the aggregate.

### Root cause

In `EventIngestionService.ingest_event_with_decision`, `_coerce_event_timestamp()` executed **before** the `try:` boundary whose `except ValidationError` handler routes failures to the dead-letter queue. A missing or malformed timestamp therefore raised `ValidationError` that escaped the service with no `dead_events` INSERT, no DLQ log/metric — a direct violation of the ingestion contract ("dead letter for validation failures") on an early-coercion edge path that only a push-only, instrument-consistency-governed gate could observe.

### Remediation (PR #699, `230fdc0dd`)

Byte-classified diff (2 files, +108/−27, no CI/role/RLS/signer/Bayesian-policy changes anywhere):

1. The early timestamp coercion is wrapped in its own `except ValidationError` that routes through the **same durable DLQ path** (`_route_validation_error_to_dlq`: identical log fields, `_route_to_dlq` write, `events_dlq_total.inc()`, `ingestion_duration_seconds.observe()`) before re-raising. `start_time` moved to the top so duration semantics are preserved for both early and late failures.
2. The pre-existing main-path handler was refactored onto the same helper — one DLQ boundary, two entry points, no behavioral change to the late path.
3. New regression test `test_missing_event_timestamp_routes_to_dlq_before_error_escapes` asserts `_route_to_dlq` is awaited with the exact tenant/event/error-type payload **before** the exception escapes.
