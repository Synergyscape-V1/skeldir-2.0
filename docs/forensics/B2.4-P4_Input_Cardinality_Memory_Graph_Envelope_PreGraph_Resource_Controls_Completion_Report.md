## 4. Preflight Lease Design and Concurrency Proof

`preflight_lease.py` reuses `b24_active_execution_leases` as the cheap DB-backed preflight lease authority. The key is:

`tenant_id`, `model_type`, `model_version`, `source_window_start`, `source_window_end`.

It excludes `source_snapshot_hash`. `INSERT ... ON CONFLICT DO NOTHING` makes one winner. Existing rows are checked `FOR UPDATE`; stale leases are recovered by `leased_until`. Losers return `acquired=False` and `fit_planner.py` marks dirty rows `suppressed` before P2/P4 work.

## 5. Resource Policy Version and Caps

Caps:

`B24_MAX_SOURCE_ROWS=250000`, `B24_MAX_TOUCHPOINTS=200000`, `B24_MAX_CONVERSIONS=75000`, `B24_MAX_CHANNELS=128`, `B24_MAX_CURRENCIES=8`, `B24_MAX_PROVIDERS=16`, `B24_MAX_CAMPAIGNS_OR_FEATURE_KEYS=2048`, `B24_MAX_WINDOW_DAYS=370`, `B24_MAX_DESIGN_MATRIX_CELLS=25000000`, `B24_MAX_TENSOR_ELEMENTS=50000000`, `B24_MAX_TENSOR_RANK=4`, `B24_MAX_INPUT_MEMORY_MB=512`, `B24_MEMORY_ESTIMATE_SAFETY_FACTOR=3`, `B24_MAX_GRAPH_NODES_ESTIMATE=100000`, `B24_MAX_RANDOM_VARIABLES_ESTIMATE=10000`, `B24_MAX_HIERARCHICAL_GROUPS=2500`, `B24_MAX_LEVELS_PER_HIERARCHY=1000`, `B24_MAX_PLATE_SIZE=250000`, `B24_MAX_PARAMETER_COUNT=100000`, `B24_MAX_TRANSFORM_OPS_ESTIMATE=50000`, `B24_MAX_LOGP_TERMS_ESTIMATE=300000`, `B24_MAX_COMPILATION_MEMORY_MB_ESTIMATE=1024`, `B24_GRAPH_COMPLEXITY_SAFETY_FACTOR=2`.

## 8. Arithmetic and Formula Proof

Memory formula:

`estimated_cells = rows * columns`

`estimated_tensor_elements = product(shape_dimensions)`

`estimated_input_memory_bytes = estimated_tensor_elements * 8 * safety_factor + fixed_overhead_bytes`

Graph formulas use only profile counts, hierarchy levels, parameter formulas, symbolic-node estimates, transform/logp estimates, and fixed compilation overhead. No allocation or graph object is constructed.

## 9. Pre-Dispatch and Dispatcher Visibility Proof

Planner order:

`dirty lease -> P4 preflight lease -> P2 snapshot -> P4 resource/graph decision -> P3 claim/outbox only if allowed`.

Fallback order:

`P4 decision fallback -> bayesian_model_fits fallback_only -> preflight lease terminalized -> dirty events fallback_only -> no outbox insert`.

Dispatcher query remains physically limited to `pending`, `failed_retryable`, and `stale_recovered`.

## 10. Fallback Semantics

- `input_too_large`
- `feature_width_exceeded`
- `source_window_too_large`
- `memory_bound_exceeded`
- `graph_complexity_exceeded`
- `parameter_count_exceeded`

`upsert_resource_fallback_from_snapshot()` sets `fallback_applied=true` and clears `sampling_started_at`, `last_fit_at`, runtime, diagnostics, artifact ref/hash, and confidence artifact fields. It does not create dispatch outbox rows.
