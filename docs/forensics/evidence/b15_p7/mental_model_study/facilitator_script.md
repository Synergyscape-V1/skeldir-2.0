# Facilitator Script (B1.5-P7 Mental-Model Study)

## Intro (read verbatim)
"You are evaluating a recommendation workflow. Please think aloud while completing tasks.
There are no right or wrong clicks; we are measuring understanding of the workflow model."

## Task Prompt 1
"Submit a new investigation question and describe what you expect to happen next."

## Task Prompt 2
"While the request is running, describe what the progress state means and whether any
decision has already been applied."

## Task Prompt 3
"When review actions appear, explain what role you play before completion."

## Task Prompt 4
"Choose approve, reject, or refine and explain why."

## Post-Task Questions
1. "Is this a chat bot giving immediate final answers, or a recommendation workflow?"
2. "Who makes the final financial decision?"
3. "What does `ready_for_review` mean in this system?"

## Scoring Note
Use `scoring_rubric.md`. Record raw answers before assigning rubric outcomes.
