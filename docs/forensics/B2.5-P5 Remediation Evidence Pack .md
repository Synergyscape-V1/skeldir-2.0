# B2.5-P5 Remediation Evidence Pack

## Scope

B2.5-P5 implements the unsigned, read-only TrustEnvelope builder boundary for
`match_verdict` subjects. The implementation intentionally stops before route
exposure, signing, JWKS, machine authentication, audit persistence, export, MCP,
and any compute dispatch.

Starting point:

- Branch: `codex/b25-p5-trust-builder`
- Base main SHA: `5cf2e8f59f8fc53c6c61b8f15689a9bc34e3d032`
- Base main subject: `Merge pull request #591 from Synergyscape-V1/codex/b25-p4-final-evidence`

## Initial Findings

- The B2.5 P1-P4 substrate was present on `main`, but P5 had no runtime builder
  boundary for producing an unsigned TrustEnvelope from a field-source adapter.
- The existing P1 trust drift guard treated new trust runtime files as drift
  unless explicitly authorized.
- The P2 serializer boundary rejected new ad hoc JSON serialization in trust
  code, so P5 needed to use the canonicalization substrate and local stable text
  rendering for tagged refusal hashes.
- P4 money authority had to remain the first authority boundary for verified
  money. P5 adapters could not pre-coerce untrusted source values into integers.

## Remediation Summary

- Added a read-only field-source adapter for `b23_match_verdicts` with tenant
  scoped SELECT-only lookup, normalized match status, deterministic completeness
  semantics, and explicit TrustEnvelope field-source coverage.
- Added an unsigned TrustEnvelope builder that:
  - supports only `match_verdict` / revenue verification match subjects;
  - refuses unsupported or wrong-tenant subjects without leaking subject data;
  - uses P4 authoritative money resolution before emitting verified revenue;
  - uses P3 text disposition for provider-controlled display text;
  - emits schema-valid, canonicalizable unsigned payloads with explicit P5
    placeholder signature/audit values;
  - records unavailable benchmark/confidence metadata truthfully;
  - performs no signing, route registration, audit writes, task dispatch, or LLM
    import/use.
- Added refusal helpers for schema-valid error envelopes and tenant hashes.
- Added policy and benchmark defaults for the read-only P5 boundary.
- Added unit tests covering success, wrong tenant refusal, prompt-control text
  quarantine, invalid money refusal, and contract-required field coverage.
- Added `scripts/ci/validate_b25_p5_builder.py` with nested P1-P4 regression
  checks, AST/transitive/dynamic import bans, runtime module tracing, read-only
  SQL controls, P3/P4 integration controls, policy/benchmark/confidence honesty,
  non-causal attribution controls, and scope-overreach checks.
- Registered the P5 validator in the CI enforcer registry and gate subsumption
  matrix, and added `.github/workflows/b2_5-p5-builder.yml`.
